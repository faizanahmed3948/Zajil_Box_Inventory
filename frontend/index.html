About roles & permissions

Employees can add boxes, generate barcodes, update box status, and export data. Admins can additionally delete boxes, clear all data, remove saved locations, and manage other users' roles. This check runs in the app itself — for full security, mirror the same admin/employee rule in your Firestore security rules so it's enforced on the server too.

Danger zone

Permanently deletes all boxes and orders. This action cannot be undone. The permanent Audit History log is kept regardless, for accountability.
